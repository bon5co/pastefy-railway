# pastefy-railway

Railway wrapper image for [Pastefy](https://github.com/interaapps/pastefy) (MIT). Pins `interaapps/pastefy:7.2.6` by digest,
requires login to create pastes, seeds an administrator and an API key from `PASTEFY_API_KEY` at boot, and listens on `$PORT`.
Built by GitHub Actions to `ghcr.io/bon5co/pastefy-railway`.
